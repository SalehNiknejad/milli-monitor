# 💛 نظارت قیمت طلا - Gold Price Monitor

یک برنامه وب مدرن و جذاب برای نظارت بر قیمت طلا 18 عیار به صورت بلادرنگ با قابلیت‌های پیشرفته.

## ✨ ویژگی‌ها

- 🔄 **بروزرسانی خودکار**: هر 10 ثانیه قیمت جدید دریافت می‌شود
- 🔔 **اطلاع‌رسانی**: دریافت اطلاع‌رسانی Windows هنگام تغییر قیمت
- 💼 **ماشین حساب کیف پول**: محاسبه میزان طلایی که می‌توانید با بودجه خود خریدید
- 💰 **محاسبه کارمزد**: درنظر گرفتن 0.5% کارمزد خرید
- 🎯 **هشدار قیمت**: تعیین هشدار برای قیمت مشخص
- 🪙 **محاسب‌گر سود**: محاسبه سود خریدهای قبلی
- 🌙 **تم شب**: حالت شب برای کاهش خستگی چشم
- 📱 **طراحی واکنش‌گرا**: سازگاری با تمام دستگاه‌ها

## 🚀 شروع سریع

### نیازمندی‌ها

- Node.js 16+
- npm یا yarn

### نصب

```bash
npm install
```

### اجرا در حالت توسعه

```bash
npm run dev
```

برنامه بر روی `http://localhost:5173` باز خواهد شد.

### ساخت برای تولید

```bash
npm run build
```

## 📝 راهنمای استفاده

### 1️⃣ نظارت قیمت

- قیمت فعلی طلا 18 عیار را مشاهده کنید
- تغییرات قیمتی را درصد‌وار ببینید
- زمان آخرین بروزرسانی را بررسی کنید

### 2️⃣ ماشین حساب کیف پول

1. موجودی کیف پول خود را وارد کنید
2. انتخاب کنید که آیا کارمزد 0.5% را شامل شود
3. نتیجه را بررسی کنید:
   - مقدار طلا قابل خریدن (میلی‌گرم)
   - هزینه کل و کارمزد
   - مبلغ خالص برای پرداخت

### 3️⃣ هشدار قیمت

1. روی "تعیین هشدار جدید" کلیک کنید
2. قیمت مورد نظر را وارد کنید
3. یا از دکمه‌های میانبر استفاده کنید (+1%، +2%، -1%، -2%)
4. وقتی قیمت به مقدار هشدار برسید، اطلاع‌رسانی دریافت خواهید کرد

### 4️⃣ محاسب‌گر سود

1. روی "افزودن خرید" کلیک کنید
2. مقدار طلا (به میلی‌گرم) و قیمت خرید را وارد کنید
3. چند خرید اضافه کنید
4. سود یا ضرر کل را مشاهده کنید

### 5️⃣ تغییر تم

- دکمه خورشید/ماه در گوشه بالا سمت چپ را کلیک کنید

## 📊 مثال‌های عملی

### محاسبه خرید با کارمزد

- موجودی: 5,000,000 ریال
- قیمت طلا: 183,060 ریال
- مقدار قابل خریدن (بدون کارمزد): 27.33 میلی‌گرم
- مقدار قابل خریدن (با کارمزد 0.5%): 27.21 میلی‌گرم
- کارمزد: 25,770 ریال

### محاسبه سود

اگر 10 میلی‌گرم طلا در قیمت 175,000 ریالی خریده‌اید:

- هزینه: 1,750,000 ریال
- قیمت فعلی: 183,060 ریال
- ارزش فعلی: 1,830,600 ریال
- سود: 80,600 ریال (4.6%)
